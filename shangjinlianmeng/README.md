# 赏金联盟自动看广

[← 返回脚本总览](../README.md)

入口：`赏金联盟自动看广.py`（社区下载版，未改写）。

每个账号登录后执行 3 次广告上报，每次间隔 20 秒。

## 青龙环境变量

```text
SJLM=账号#密码[#账号#密码]...
```

多账号按「账号#密码」两两成组，用 `#` 串联。

## 定时

```text
0 9 * * *
```

## 依赖

```text
requests
```

## 说明

- 脚本来自 `http://ql.xmox.cn` 脚本库，仅使用其 HTTP 接口
- 暂无 Bark 通知；需要通知可在青龙面板「通知设置」统一配置
- 仅供学习交流，账号风险自负
